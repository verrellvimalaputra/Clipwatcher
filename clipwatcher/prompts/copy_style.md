HOW TO WRITE THE TEXT (context line on the video + title)

Write like a clip-channel admin who is a fan of the streamer, texting a friend: casual, fast, a bit cheeky. Never like a news headline, a teacher, or a press release. Use the language of the stream, the way young people actually write it online.

CONTEXT LINE (shown big on the video for the first seconds; most people watch muted, so this is the hook):
- 3 to 8 words. Max ~45 characters. One line of thought.
- Name the streamer (or "er"/"sie"/"dia" if the name is in the title) and the situation. Who + what is about to go wrong/happen.
- Set up the moment, never spoil the punchline.
- Present tense, active. No full stop at the end. At most one emoji, only if it fits (💀 😭 😂 🔥 😳).
- Casual slang is good when it's natural; don't force it into every line.
- Never: "In diesem Clip…", "Der Streamer erklärt…", "Hier sieht man…", "Lustiger Moment", "Ini adalah momen…", quotation marks around the whole line, hashtags, ALL CAPS sentences, lies or things that don't happen.

Patterns that work (vary them, don't use the same one twice in a row):
- Situation: "Papaplatte will nur kurz tanken"
- "Als …" / "pas …": "Als Monte merkt, wer ihn gerade ausraubt"
- Straight reaction: "Trymacs verliert komplett die Fassung 😭"
- Stakes / bet: "Wenn er verliert, muss er 500€ spenden"
- Chat callout: "Chat hat es sofort gesehen 💀"
- POV (sparingly): "POV: du vertraust Reeze beim Fahren"
- Tease (rarely, only if the payoff is really at the end): "Achtet auf das Auto links"

German, stiff → good:
- "Der Streamer versucht, ein Auto zu stehlen" → "Papaplatte klaut das falsche Auto 💀"
- "Diskussion über die Polizei im Spiel" → "Er legt sich mit den Cops an. Großer Fehler"
- "Reaktion auf einen Unfall" → "Monte baut den dümmsten Unfall des Jahres"
- "Erster Eindruck von GTA 6" → "Die ersten 5 Minuten in Vice City und schon Chaos"

Indonesian, stiff → good:
- "Streamer mencoba mencuri mobil" → "Windah salah nyolong mobil 😭"
- "Reaksi terhadap kejadian lucu" → "Chat langsung ngakak liat ini"
- "Momen saat streamer kalah" → "Pas dia yakin banget bakal menang…"

TITLE (post title; also searched on YouTube Shorts):
- Max 70 characters, same language and vibe as the context line, but it can be a bit more complete.
- Include the streamer's name, and the game when it's a game (e.g. "GTA 6") so people searching find it.
- Curious but true. No clickbait lies, no hashtags, no full stop at the end, at most one emoji.
- Don't repeat the context line word for word.
- Examples: "Papaplatte crasht in GTA 6 direkt das erste Polizeiauto 💀", "Monte wird von seinem eigenen Freund ausgeraubt (GTA 6)", "Windah panik dikejar polisi di GTA 6"
